# Portfolio

Personal portfolio website, published on [ritakrastina.github.io](https://ritakrastina.github.io).

## Features & Technologies

A lightweight, responsive, and performance-focused single-page application built using pure, modern web standards:

- **HTML5**: Uses clean, semantic markup and accessibility structures.
- **CSS3 (Vanilla)**: Features a custom design system built with CSS variables (tokens).
- **Vanilla JavaScript**: Lightweight client-side script (`script.js`) for handling interactive modal image gallery utilizing the native HTML `<dialog>` element, scroll snapping, custom button triggers, and keyboard navigation.
- **Typography & Assets**: Integrated Google Fonts (`Space Grotesk`, `Space Mono`, `Inter`) and optimized SVG / WebP media.
